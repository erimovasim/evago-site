# EVAGO — сайт

Сайт вызова эвакуатора и помощи на дороге (Алматы). Один файл `index.html`: HTML + CSS + JS, без сборки.

- Открыть: двойной клик по `index.html` или Live Server в VS Code
- Настройки (телефон, WhatsApp, цены, цифры): блок `CONFIG` в конце `index.html`
- Языки: KZ / RU
- План проекта: папка `docs/`
