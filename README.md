# EVAGO — сайт

Вызов эвакуатора и помощи на дороге (Алматы). Статический сайт (HTML/CSS/JS) + база Supabase.

## Страницы
- `index.html` — главная
- `order.html` — оформление заказа: карта, геолокация, откуда/куда, тип авто, цена
- `track.html` — статус заказа для клиента (обновляется сам, водитель на карте)
- `driver.html` — заявка «стать водителем»
- `admin.html` — **панель диспетчера** (вход по email): заказы приходят со звуком, назначение водителя, статусы, заявки водителей
- `drive.html` — страница водителя по ссылке из панели: заказ, звонок клиенту, навигатор, статусы, отправка местоположения

## Настройки
`assets/app.js` → блок `EVAGO`: телефон, WhatsApp, Instagram, цены.

## База
`supabase/02_dispatcher.sql` — SQL для панели диспетчера и трекинга водителя.
