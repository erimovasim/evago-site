# EVAGO – Project Foundation v1

**Мақсаты:  
**Қазақстан бойынша эвакуатор мен жолдағы көмекті жылдам, сенімді және
қарапайым түрде ұсынатын платформа.

## Бренд

Атауы: EVAGO  
Стиль: Apple минимализмі + сенімді сервис.  
Түстер: Ақ, қара, сары акцент.

## Мақсатты аудитория

20–50 жас, жеке көлік иелері, такси жүргізушілері, бизнес.

## Құндылықтар

Сенімділік, жылдамдық, қарапайымдылық, қауіпсіздік, ашықтық.

## MVP функциялары

Телефонмен кіру, карта, маршрут таңдау, көлік түрі, жүргізушілер
ұсынысы, болжамды баға + нақты ұсыныстар, фото(3), дауыс(30 сек), чат,
қоңырау, трекинг, рейтинг, пікір, төлем.

## Клиент жолы

Splash → Welcome → Телефон → Геолокация → Home → Маршрут → Ұсыныстар →
Tracking → Төлем → Бағалау

## Driver App

SMS кіру, құжаттарды тексеру, Online/Offline, ұсыныс жіберу, навигация,
тапсырысты аяқтау, табыс статистикасы.

## Admin

Users, Drivers, Orders, Payments, Reviews, Dashboard.

## Дизайн

Минимализм, толық экран карта, төменгі панель, 3 бөлім: Басты,
Тапсырыстар, Профиль.
