**EVAGO**

**Толық техникалық жоспар (Technical Blueprint)**

Алматы · MVP · Клиент қосымшасынан бастау

*Стек: Flutter · Firebase · Google Maps*

**0. Жоба туралы қысқаша**

EVAGO — Алматы қаласында эвакуатор мен жол көмегін жылдам шақыруға
арналған мобильді платформа. Клиент қосымша арқылы орналасқан жерін
белгілеп, эвакуатор шақырады; жақын жүргізушілер ұсыныс жібереді; клиент
таңдап, келуін картадан бақылайды.

Бұл құжат — жобаның техникалық негізі (blueprint). Мұнда MVP-ге кіретін
функциялар, экрандар тізімі, дерекқор құрылымы, файл құрылымы және іске
асыру кезеңдері жазылған. Код жазу барысында осы құжатқа сүйенеміз.

**Таңдалған технологиялар және неге**

| **Қабат** | **Технология**           | **Себебі**                                                  |
|-----------|--------------------------|-------------------------------------------------------------|
| Frontend  | Flutter                  | Бір кодтық база — Android + iOS. Тез әзірлеу.               |
| Backend   | Firebase                 | Телефон+SMS авторизация дайын, real-time база, push кіреді. |
| Карта     | Google Maps              | Тұрақты, жылдам, қатпайды. Ресми Flutter плагині.           |
| Дерекқор  | Cloud Firestore          | Real-time, тапсырыс пен жүргізуші орнын лезде жаңартады.    |
| Хабарлама | Firebase Cloud Messaging | Жаңа тапсырысты жүргізушіге бірден жеткізу.                 |

**1. MVP көлемі (нені жасаймыз, нені жасамаймыз)**

**MVP — ең қарапайым, бірақ жұмыс істейтін нұсқа. Мақсат: клиент
эвакуатор шақыра алуы және жүргізуші оны қабылдап, келуі. Артық
функцияларды кейінге қалдырамыз.**

**MVP-ге КІРЕДІ (Клиент)**

- Телефон нөмірі + SMS код арқылы кіру

- Картадан геолокацияны автоматты анықтау

- «Қайдан / Қайда» нүктелерін белгілеу

- Көлік түрін таңдау (жеңіл, кроссовер, микроавтобус)

- Болжамды бағаны көрсету

- «Эвакуатор шақыру» — жақын жүргізушілерге жіберу

- Жүргізушінің келуін картадан бақылау (real-time)

- Тапсырыс аяқталғанда бағалау (жұлдыз + пікір)

**MVP-ге КІРЕДІ (Жүргізуші — минимум)**

*Клиент қосымшасы жұмыс істеу үшін жүргізуші жағы да керек, бірақ ең
қарапайым түрде:*

- Онлайн / офлайн ауысу

- Жаңа тапсырысты көру және қабылдау

- Өз орнын серверге жіберіп отыру (клиент бақылауы үшін)

**КЕЙІНГЕ қалдырамыз (MVP-ден кейін)**

- Қосымша қызметтер: аккумулятор, дөңгелек, жанармай, көлік ашу

- Аукцион (жүргізушілер баға ұсынысы) — алдымен фикс баға

- Онлайн төлем (Kaspi / карта) — алдымен қолма-қол

- Чат, дауыс хабарламасы, фото жіберу

- SOS батырмасы, промокод, жүргізуші статистикасы

*Себебі: осылардың бәрін бірден жасасақ, айлап кетеді. Алдымен негізгі
айналымды («шақыру → келу → бағалау») жұмыс істетеміз.*

**2. Клиент қосымшасының экрандары (MVP)**

Экрандар реті — қолданушы жолы бойынша:

| **№** | **Экран**          | **Не істейді**                                           |
|-------|--------------------|----------------------------------------------------------|
| 1     | Splash             | Логотип, 2 секунд, жүктелу.                              |
| 2     | Welcome            | Қысқаша таныстыру, «Бастау» батырмасы.                   |
| 3     | Авторизация        | Телефон нөмірі енгізу → SMS код тексеру.                 |
| 4     | Геолокация рұқсаты | Локацияға рұқсат сұрау.                                  |
| 5     | Home (карта)       | Толық экран карта, «Қайдан/Қайда», көлік түрі, «Шақыру». |
| 6     | Ұсыныстар / Іздеу  | Жақын жүргізуші ізделуде немесе баға көрсету.            |
| 7     | Трекинг            | Жүргізуші картада қозғалады, келу уақыты, қоңырау.       |
| 8     | Тапсырыс аяқталды  | Бағалау: жұлдыз + пікір (міндетті емес).                 |
| 9     | Профиль            | Аты, нөмірі, тапсырыс тарихы, шығу.                      |

**3. Дерекқор құрылымы (Firestore)**

Firestore — құжаттық база. Негізгі коллекциялар (collections):

**users (клиенттер)**

| **Өріс**  | **Түрі**  | **Сипаттама**           |
|-----------|-----------|-------------------------|
| uid       | string    | Firebase Auth id (кілт) |
| phone     | string    | Телефон нөмірі          |
| name      | string    | Аты (кейін толтырады)   |
| rating    | number    | Орташа рейтинг          |
| createdAt | timestamp | Тіркелген уақыты        |

**drivers (жүргізушілер)**

| **Өріс**  | **Түрі** | **Сипаттама**           |
|-----------|----------|-------------------------|
| uid       | string   | Firebase Auth id        |
| name      | string   | Аты-жөні                |
| phone     | string   | Телефоны                |
| carType   | string   | Эвакуатор түрі          |
| carNumber | string   | Мемлекеттік нөмірі      |
| isOnline  | bool     | Онлайн/офлайн           |
| location  | geopoint | Ағымдағы орны (lat/lng) |
| rating    | number   | Рейтингі                |

**orders (тапсырыстар)**

| **Өріс**  | **Түрі**  | **Сипаттама**                                   |
|-----------|-----------|-------------------------------------------------|
| orderId   | string    | Тапсырыс id                                     |
| clientId  | string    | Клиент uid                                      |
| driverId  | string    | Қабылдаған жүргізуші (басында бос)              |
| fromPoint | geopoint  | Қайдан                                          |
| toPoint   | geopoint  | Қайда                                           |
| carType   | string    | Көлік түрі                                      |
| price     | number    | Болжамды баға                                   |
| status    | string    | searching / accepted / onway / done / cancelled |
| createdAt | timestamp | Құрылған уақыты                                 |
| rating    | number    | Клиент қойған баға                              |

*status өрісі — ең маңыздысы. Тапсырыс осы күйлер арқылы өтеді:
searching (ізделуде) → accepted (қабылданды) → onway (жолда) → done
(аяқталды).*

**5. Іске асыру кезеңдері (жол картасы)**

Әр кезеңді реттеп жасаймыз. Уақыт — бір адам жарты күн жұмыс істесе,
шамамен:

| **Кезең**         | **Не істейміз**                                                       | **Уақыт (шам.)** |
|-------------------|-----------------------------------------------------------------------|------------------|
| 1\. Дайындық      | Flutter орнату, GitHub репо, Firebase жоба құру, Google Maps API кілт | 2-3 күн          |
| 2\. Негіз         | Жоба құрылымы, тема (түс/шрифт), навигация, Splash + Welcome          | 2-3 күн          |
| 3\. Авторизация   | Телефон + SMS кіру, users құру                                        | 3-4 күн          |
| 4\. Home экран    | Google Maps, геолокация, Қайдан/Қайда, көлік түрі                     | 5-7 күн          |
| 5\. Тапсырыс      | «Шақыру» → orders құру → Firestore-ға жазу                            | 4-5 күн          |
| 6\. Трекинг       | Жүргізуші орнын real-time көрсету, статус                             | 5-7 күн          |
| 7\. Бағалау       | Тапсырыс аяқтау, рейтинг, профиль, тарих                              | 3-4 күн          |
| 8\. Жүргізуші min | Жүргізуші жағы: онлайн, тапсырыс қабылдау, орын жіберу                | 5-7 күн          |
| 9\. Тест          | Нақты телефонда тексеру, қателерді түзету                             | 3-5 күн          |

**Барлығы: шамамен 5-7 апта (MVP, бір адам). Асықпай, кезеңмен жүрсек —
тұрақты нәтиже.**

**6. Ең бірінші нақты қадам**

Осы құжат бекітілгеннен кейін, 1-кезеңнен бастаймыз. Дәйектілік:

1.  Flutter SDK орнату және тексеру (flutter doctor)

2.  GitHub-та жаңа репозиторий құру (evago_client)

3.  Firebase консолінде жоба ашу, Flutter-ге жалғау

4.  Google Cloud-та Maps API кілтін алу

5.  Бос Flutter жобасын құрып, алғашқы commit жасау

*Осының әрқайсысын мен саған қадам-қадам көрсетемін — команда, код,
скриншот деңгейінде.*
