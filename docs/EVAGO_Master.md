## 1. Что такое EVAGO

Платформа для быстрого вызова эвакуатора и помощи на дороге по Казахстану, старт MVP — Алматы.
Цель: быстро помочь человеку в трудный момент на дороге и дать надёжный сервис.

- **Слоганы:** «Жолда жалғыз емессің» · «Жолда сенімді көмек әрқашан жақында»
- **Ценности:** сенімділік, жылдамдық, қарапайымдылық, ашықтық, қауіпсіздік
- **Аудитория:** 20–50 лет, владельцы личных авто, таксисты, бизнес
- **Почему есть спрос:** в Казахстане эвакуатор вызывают в основном по телефону или WhatsApp, удобных приложений мало

## 2. Дизайн

- Стиль: минимализм как у Apple, спокойный, деловой, надёжный
- Шрифт: SF Pro Display / Inter
- Цвета: `#FFFFFF` белый · `#111111` чёрный · `#FFD200` жёлтый акцент · `#F5F5F5` светло-серый · `#007AFF` синий (маршрут/ссылки) · `#FF3B30` красный (SOS/ошибки)
- Приложение: полноэкранная карта, нижняя панель, нижнее меню из 3 разделов — Басты, Тапсырыстар, Профиль
- Driver App — тёмная тема (чёрный фон, жёлтые/зелёные акценты)
- Языки: қазақша + русский

## 3. Как работает (клиент)

1. Открывает приложение
2. Карта сама определяет местоположение
3. Отмечает, куда везти
4. Выбирает тип авто (жеңіл, кроссовер, микроавтобус, мотоцикл, басқа)
5. Видит цену
6. Нажимает «Эвакуатор шақыру»
7. Заказ уходит ближайшим эвакуаторам
8. Когда водитель принял, клиент видит его на карте

**Путь клиента (экраны):** Splash (лого + слоган, 2 сек) → Welcome («Бастау») → Авторизация (телефон + SMS) → Разрешение геолокации → Home (Қайдан, Қайда, тип авто, «Көмек керек») → Тип авто → Доп. информация (фото до 3, голосовое до 30 сек, текст, отметки: көлік оталмайды, жол апаты, двигатель бұзылған, кюветте, басқа) → Ұсыныстар (болжамды баға + предложения водителей с рейтингом и временем) → Трекинг (водитель едет, время прибытия, звонок/чат) → Тапсырыс аяқталды (звёзды + пікір) → Профиль

**Типы заказа:** Аукцион или Фикс баға.
**Профиль:** история заказов, способ оплаты, адреса, пригласить друзей, промокоды, поддержка, настройки, выход.

## 4. Водитель (Driver App)

Вход по SMS, проверка документов, онлайн/офлайн, новые заказы, отправка своей цены, навигация к клиенту, звонок/чат клиенту, завершение заказа, статистика дохода (сегодня/неделя/месяц), рейтинг EVAGO Score, уведомления.

## 5. Админ-панель

Users, Drivers, Orders, Payments, Reviews, Dashboard; управление тарифами, статистика.

## 6. Архитектура

EVAGO Backend API → Client App, Driver App, Admin Panel → Website / Landing Page.

## 7. Оплата и заработок

- Клиент платит (наличными или онлайн) → EVAGO берёт комиссию → водитель получает остаток на баланс и выводит когда хочет
- Способы: наличные, банковская карта, Kaspi Pay (позже)
- Модель дохода: комиссия 10–15% с заказа, или ежемесячная подписка для водителей, или оба

## 8. Особые функции (преимущества)

SOS-кнопка (помощь в один клик) · голосовое сообщение (не надо печатать) · проверенные водители · EVAGO Score (рейтинг качества водителя)

## 9. Технологии

- **Technical Plan:** Flutter · Firebase (Auth телефон+SMS, Firestore, FCM push) · Google Maps
- В других заметках также рассматривались Supabase и Яндекс Карты

## 10. MVP по Technical Plan (что делаем сначала)

**Клиент:** вход телефон+SMS, геолокация, Қайдан/Қайда, тип авто (жеңіл, кроссовер, микроавтобус), болжамды баға, вызов ближайшим водителям, real-time трекинг, оценка.
**Водитель (минимум):** онлайн/офлайн, видеть и принимать заказ, отправлять своё местоположение.
**На потом:** аккумулятор, дөңгелек, жанармай, көлік ашу; аукцион (сначала фикс цена); онлайн-оплата (сначала наличные); чат, голос, фото; SOS, промокод, статистика водителя; кран-манипулятор, бронь заранее.

> Заметка: в Foundation v1.2 и на макетах аукцион, фото, голос, чат и оплата отнесены в MVP, а в Technical Plan — на потом. Основным порядком работы считаем Technical Plan.

## 11. База данных (Firestore)

- **users:** uid, phone, name, rating, createdAt
- **drivers:** uid, name, phone, carType, carNumber, isOnline, location (geopoint), rating
- **orders:** orderId, clientId, driverId, fromPoint, toPoint, carType, price, status, createdAt, rating
- **status:** searching → accepted → onway → done (или cancelled)

5. Заказ → запись в orders — 4–5 дней
6. Трекинг real-time — 5–7 дней
7. Оценка, профиль, история — 3–4 дня
